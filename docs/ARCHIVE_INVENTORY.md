# Repository inventory

The repository contains the finalized Energy Economics model code, processed inputs, and execution instructions. Generated outputs remain in the local model archive and are not version-controlled.

| Category | Included in GitHub |
| --- | --- |
| Executable workflow | `main.ipynb`, Python modules, and configuration |
| Cost inputs | Exchange-rate XML files |
| Sourcing inputs | Processed B1 and B2 workbooks |
| Industrial mapping | C1 workbook, classification files, and metadata |
| MRIO inputs | Prepared FIGARO 2024 industry-by-industry core/ROW matrix |
| Reproducibility | README, requirements, environment setup, and documentation |

Generated figures, tables, supplementary output workbooks, scenario caches, downloaded employment source files, and full FIGARO flatfiles are not included. The notebook generates results in `results/` when the corresponding export options are enabled.
